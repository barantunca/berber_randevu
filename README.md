# Randevu Defteri

Berberler için basit randevu takip uygulaması. Telefondan aç, kullan.

Kağıt defterin dijital hali. Müşteri randevu almaz, sen randevularını yazarsın.

## Kullanım

- Bir saate tıkla, müşteri adını yaz.
- Sağa kaydır, müşteri geldi demek.
- Sola kaydır, randevuyu sil.
- Ok tuşlarıyla günler arası gez.

## Kurulum

Dosyaları bir sunucuya at. Vercel, Netlify, her yere olur. Hepsi bu.

Veriler telefonun tarayıcısında kalır. İnternet giderse bile çalışır.
